## 6. Deployment gotchas (read before deploying ANYTHING)

1. **A PARALLEL SESSION keeps overwriting 187's tree** (`git archive HEAD | tar xf - -C ~/altacloset` from a possibly-stale clone) **and recreating the webapp container.** Consequences:
   - scp'd host files revert within seconds → **`docker cp` the corrected files directly into the RUNNING container**, then **verify SERVED content** (curl + grep), not just the container file.
   - Container recreate **loses 187 `.env` COMFYUI_URL override** (reverts to `http://comfyui:8188`, unresolvable on 187) → try-on 500 "Temporary failure in name resolution". Fix: re-append `COMFYUI_URL=http://10.0.1.187:28190` to 187 `~/altacloset/.env` + `docker compose up -d --force-recreate webapp`.
   - Parallel session re-bumps version (now **0.39.0**) — pulled our origin commits, so app code is safe in the tree. The code we commit locally IS the truth; deploy via docker cp after any recreate.
2. **`docker cp` does NOT read stdin.** Use scp→187 tree→docker cp (or tar pipe). Verify with md5sum inside container (`docker exec ... md5sum`).
3. **`node --check static/js/*.js` before every JS deploy** (IDE linting misses syntax errors in page scripts). Also grep for **duplicate `const`/function names across common.js + page scripts** (v0.37.3 lesson — kills the whole page).
4. **Workflow JSON files must be committed + scp'd to 187** before deploying (they're loaded by the webapp, not baked in).
5. `/api/uploads/*` is **token-auth'd** — never give raw render URLs; point users to the app page.
6. Renders serve `Cache-Control: private, no-cache` (commit `d41f721`) — a hard reload must show fresh renders.
